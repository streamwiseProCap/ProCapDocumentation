## Selecting objects

Click an object in the 3D view, for example a model or a visualization plane, to select it. The selected object gets an orange outline, its transform gizmo and a bar of quick actions. When you point at an object without selecting it, its outline is light blue.

## Quick actions

The quick actions are a small bar of icons that appears above the selected object. They give you the most common commands without opening a panel. Which icons appear depends on the object.

| Icon | Action | Description |
| --- | --- | --- |
| Eye | **Show or hide** | Shows or hides the object. The eye is struck through while the object is hidden. A hidden object stays selected and shows only its outline, so you can show it again. |
| Clipboard with pen | **Edit** | Opens the settings panel of the object. |
| Axes or square with pen | **Move or edit shape** | Switches between the transform gizmo and the shape handles of the object. Only for objects with a shape you can edit. |
| Two sheets | **Duplicate** | Adds a copy of the object. Not available when your edition's limit for this kind of object is reached. |
| Bin | **Delete** | Deletes the object. |
| Lock | **Lock color map** | Keeps the legend of the object on the screen after you select something else. Only for objects with a color legend, for example [visualization planes](../visualization/visualization-planes.md#the-legend). |
